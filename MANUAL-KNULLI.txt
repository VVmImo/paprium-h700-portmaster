PAPRIUM H700 — KNULLI GUIDE — alpha 0.5.2 EXPERIMENTAL

STATUS: PREPARED PACKAGE, NOT HARDWARE-TESTED ON KNULLI.
English documentation and installer-language revision; audio behavior
is unchanged from 0.5.1. The ARM64 engine was used on muOS, which does not
prove KNULLI video, audio, controls, conversion or menu-return compatibility.
Do not replace your firmware to install this package.

1. DOWNLOAD AND REQUIREMENTS
Use Paprium-H700-KNULLI-alpha-0.5.2-EXPERIMENTAL.tar.gz.
The muOS .muxupd uses a different format and must not be used on KNULLI.
Requires KNULLI on H700 ARM64, firmware SDL2 and working PortMaster.
Direct dependencies: libc, libm and libdl. SDL2 is loaded dynamically.
Required GLIBC symbols are up to 2.29. Real firmware/driver compatibility
is still unverified. The included music converter is also ARM64.

KNULLI documents PortMaster installation under:
  Start → Device Settings → Install Portmaster
Reference: https://knulli.org/systems/portmaster/
Update PortMaster before testing.

No game data is included. Allow at least 3 GB free AFTER copying ROM and
MP3 files for the reference soundtrack; generated WAV files occupy about
2.24 GB. Other track lengths may need more. Keep sufficient power during
conversion. No Internet, FFmpeg or Python is needed for preparation.

2. EXTRACT AND COPY BOTH INSTALLER ITEMS
Extract the TAR.GZ on your PC. If the extractor first produces a TAR,
extract that too. Copy BOTH items into roms/ports on the SHARE partition:
  Install Paprium.sh
  paprium-knulli/       [complete folder, including files and install.sh]

Exact SFTP paths:
  /userdata/roms/ports/Install Paprium.sh
  /userdata/roms/ports/paprium-knulli/install.sh
  /userdata/roms/ports/paprium-knulli/files/Paprium.sh
  /userdata/roms/ports/paprium-knulli/files/paprium/paprium.aarch64
Network-share equivalents:
  SHARE/roms/ports/Install Paprium.sh
  SHARE/roms/ports/paprium-knulli/

With a card reader, use roms/ports on SHARE, not the boot partition. If
your PC cannot read that partition, use SFTP or the network share; do not
reformat it. /userdata follows KNULLI's selected data storage, without
imposing SD1 or SD2. KNULLI roms/ports names are lowercase.

3. INSTALL FROM PORTS
1) Update the game list: Start → Game Settings → Update Gamelists,
   depending on the firmware version and menu language.
2) Open Ports and select Install Paprium.
3) Wait for completion. The installer checks hashes, firmware,
   architecture and basic executable startup, then copies software only.
4) Update the game list again. Paprium should appear in Ports.

Installed files should include:
  /userdata/roms/ports/Paprium.sh
  /userdata/roms/ports/paprium/paprium.aarch64
  /userdata/roms/ports/paprium/paprium-convert.aarch64
  /userdata/roms/ports/paprium/prepare-music.sh
  /userdata/roms/ports/paprium/music-tracks.txt
  /userdata/roms/ports/paprium/INSTALL-KNULLI.txt
  /userdata/roms/ports/paprium/licenses/
  /userdata/roms/ports/paprium/source.tar.gz
  /userdata/roms/ports/paprium/relink.tar.gz

The package does not modify /usr/bin, custom.sh, knulli.conf or the global
EmulationStation catalogue. No RetroArch core is installed. The launcher
uses PortMaster controls/platform preparation and cleanup. It does not
stop or restart EmulationStation itself.

Installer log: /userdata/roms/ports/paprium-knulli/install.log
Passing --version does not prove that game video/audio will initialize.
Close Paprium before updating. After confirming installation, you may move
Install Paprium.sh and paprium-knulli out of ports to keep only the game
entry visible. Keep the original package on your PC for reinstalling.

4. EXACT GAME-DATA DESTINATIONS
Create gamedata and gamedata/paprium inside the INSTALLED paprium folder
if missing. Copy the uncompressed ROM, named exactly paprium.bin, to:
  /userdata/roms/ports/paprium/gamedata/paprium.bin
  SHARE/roms/ports/paprium/gamedata/paprium.bin
Copy all 52 correctly named MP3 files directly into:
  /userdata/roms/ports/paprium/gamedata/paprium/
  SHARE/roms/ports/paprium/gamedata/paprium/
Example:
/userdata/roms/ports/paprium/gamedata/paprium/01 Theme of Paprium.mp3

Do NOT put game data in paprium-knulli/files: that is installer input,
not the running game's location. Avoid extra nested folders, duplicate
hidden extensions and compressed ROM files. A separate paprium.wav is
not required and cannot replace the 52 named tracks. Valid matching WAV
files may be supplied instead of MP3 files.

5. REFERENCE DATA AND COMPATIBILITY
Reference ROM used during muOS development:
  Name: paprium.bin
  Exact size: 8,388,608 bytes (8 MiB)
  Product identifier: T-574120-00
  SHA-256:
  f9192ac55b915ac65765688bd4944c98d4ebe2ea994e6d312e2e6e52f7e79d09
The same input format is expected on KNULLI but remains hardware-untested.
A different hash identifies another revision, not automatic incompatibility.
Do not edit headers to bypass identification. From an SSH shell:
  sha256sum /userdata/roms/ports/paprium/gamedata/paprium.bin

The appendix and music-tracks.txt list exact names. Keep all numbers,
spaces and punctuation. The converter generates PCM16 stereo WAV at
48 kHz. The core accepts mono/stereo WAV at 8–48 kHz; prefer 48 kHz.
Matching names and valid formats alone do not prove correct music content.

6. FIRST LAUNCH AND CONVERSION
In Ports select the Paprium FILE (Paprium.sh), not its folder.
Preparation reuses valid WAV files and converts missing ones from matching
MP3 files. If both formats are missing for a track, it stops before
conversion and identifies that track. With 52 MP3 files and no WAV files,
expect "Converting music 1/52: ..." and subsequent progress.
Keep the device powered and wait. The game starts after preparation.

MP3 files are retained. WAV files are written beside them. Later launches
reuse valid WAV files. After a failure, fix the cause and retry: completed
valid WAV files are preserved. An invalid WAV is not overwritten; move it
outside the music folder and supply its MP3 to regenerate it. A black
screen alone does not prove conversion is running: check log.txt and
conf/conversion-status.txt. Updating does not require reconversion.

7. CONTROLS, EXIT AND SAVES
Intended SDL/PortMaster mapping; still unverified on KNULLI hardware:
  D-pad / left stick: directions
  Left / bottom / right / top face: Mega Drive A / B / C / X
  L1 / R1: Y / Z
  Start / Select: Start / Mode
  Select + Start: normal exit
  Select + R1: soft reset
If the initial minigame appears, hold Select and tap R1 when it is
playable. If it does not progress, preserve the log. Reset is not the
normal exit. Two-controller operation still needs physical testing.

SRAM: /userdata/roms/ports/paprium/saves/paprium.srm (65,536 bytes).
Changes are checked every five seconds and on normal exit. Only progress
saved by the game is retained; there are no savestates. Close the game
before copying/restoring SRAM. Existing wrong-size SRAM is not overwritten.
Audio retains the 0.5.1 effects filter and per-voice gain fix; music is
outside that effects filter. Original 4/8-bit data still limits fidelity.

8. TROUBLESHOOTING AND REQUIRED HARDWARE TESTS
Game log: /userdata/roms/ports/paprium/log.txt
Music status: /userdata/roms/ports/paprium/conf/conversion-status.txt
Installer log: /userdata/roms/ports/paprium-knulli/install.log

No entry: verify paths and update the game list.
A folder opens: select the Paprium.sh file instead.
Missing control.txt: install/update PortMaster for KNULLI.
GLIBC/SDL2 errors: the firmware/library combination is incompatible with
this binary. Report model, KNULLI version and exact error. Do not copy
muOS libraries over firmware libraries.
Conversion failure: check exact names, free space and the indicated MP3.
Black screen, unresponsive controls, absent audio or no return to Ports:
preserve the log and describe the behavior. Real hardware tests are needed.
Do not describe the package as KNULLI-validated until those tests pass.

Checklist: installation, complete conversion, video, six-button controls,
music/effects, Select+Start exit, return to Ports, relaunch and SRAM retention.
For a clean test, close the game and remove ONLY installed Paprium.sh and
paprium. This removes that installation's data/saves; do not delete ports
or SHARE. Reinstall and supply ROM plus MP3 files to retest conversion.
An SRAM copy before removal is optional.
